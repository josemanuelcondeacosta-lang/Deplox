# Deplox

Web corporativa estática en español. `dist/` contiene todos los archivos para desplegarla en cualquier hosting estático. Sin dependencias de construcción.

La primera propuesta utiliza el logo A y su paleta cian. Los proyectos y canales comerciales están pendientes de la información del propietario; la web los identifica como próximos, sin inventar clientes o entregas.

Para una vista local: `python -m http.server 8080 --directory dist`.

Las fuentes de Google Fonts son opcionales; hay fuentes de sistema alternativas.
